Why your coding agent
gets worse as the
project grows

Brandon Garate · VibeDrift · github.com/VibeDrift/VibeDrift

The thing you've all hit

Your agent writes a function
you already have.

Second one is in a different folder, named differently, doing the same job. Nobody notices until the third one shows up.

Why it happens

Every session starts blind.

  • The agent sees the files it opened, not the repo.
  • It has no memory of the conventions the last twenty sessions established.
  • So it does the reasonable thing: it writes fresh code that works.
  • Each one is defensible. The twentieth one is a mess.

This gets worse as the repo grows, because the fraction the agent can see keeps shrinking.

The core idea

No finding
without a baseline.

Drift is a deviation from a peer group. If there's no group, there's no finding.

What that costs us

We can't tell you your code is bad.
Only that it disagrees with itself.

There's no rule list. We don't know if you should use tabs. We know that 440 files here use PascalCase and 72 don't, and that the 72 are the ones the agent wrote last week.

It's not a quality score. It's a consistency score. Those are different products and we keep having to say so.

Where it runs

Before it writes,
not after you review.

An MCP server the agent can call mid-session. Same classifier as the batch scan, so the answer in-loop can't contradict the answer in the report.

claude mcp add vibedrift \
  -- npx -y @vibedrift/cli mcp

# agent, mid-edit:
validate_change(file, contents)
  → fits: true | false | null

Three states, not two. null means we don't know, and we'd rather say that than guess.

Running now · ~20 seconds

What it's doing
while we wait

  • Groups files by directory, because conventions are local.
  • Votes on the dominant pattern in each group.
  • Needs 70% agreement to call it a convention at all.
  • Weights code from this week about twice as heavily as code from three months ago.

Below 70%, it reports nothing. A repo that never agreed with itself has no convention to drift from.
